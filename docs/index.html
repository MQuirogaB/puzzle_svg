Generador de puzles

Elige el tamaño, el número de piezas y el tipo de pieza y descarga un SVG para cortar con láser. Todo va de un solo color y cada línea de corte aparece una sola vez, así que el láser no pasa dos veces por el mismo sitio. Todo ocurre en tu navegador: no se sube nada a ningún servidor.

Ajustes de las piezas Lengüetas, ondas y semilla

Columnas y filas solo valen en rejilla cuadrada o triangular. Con la misma semilla y los mismos ajustes sale siempre el mismo puzle.

Marco y base Opcionales

El marco es un anillo que rodea al puzle (el corte exterior del puzle es también el borde interior del marco, así que se corta una sola vez). La base es una placa del mismo tamaño total, para pegar el marco encima.
